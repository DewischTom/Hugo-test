Inhalte mit Markdown

Oktober 11, 2026

Mit Markdown kannst du Texte einfach strukturieren und formatieren. Lerne Überschriften, Listen und Hervorhebungen kennen.

Was ist Markdown?

Markdown ist eine einfache Auszeichnungssprache. Mit wenigen Zeichen lassen sich Texte formatieren.

Hugo wandelt diese Inhalte beim Erstellen der Website in HTML um.

Überschriften

Eine Überschrift wird mit einem oder mehreren Rautezeichen geschrieben.

Zum Beispiel:

## Meine Überschrift

Listen

Mit einem Bindestrich kannst du eine Liste erstellen:

- Erster Punkt
- Zweiter Punkt
- Dritter Punkt

Hervorhebungen

Mit Sternchen kannst du Wörter hervorheben:

**Dieser Text ist fett.**
*Dieser Text ist kursiv.*
